3. Add the new configuration options on `Config.Zombies` section.

```lua

    -- This feature is to allow the zombies to wander around when havent focused on a player target yet.
    -- If you set it to false, the zombies will stay as "frozen" and just wait for a target.
    AllowWandering = true, -- 3.0.7 version

    -- When enabled, players will be able to cover themselves with guts and wont be tracked for 
    -- an amount of time (except if they shoot or be on a horse or on a vehicle).
    -- It will also not work on zombies who already targetted the player.
    GutsCovering = true, -- 3.0.7 version

    -- For how long should a player not be tracked by zombies (if not shooting or being on a mount or vehicle)
    GutsCoveringTime = 5, -- The time in minutes - 3.0.7 version

    GutsCoveringType = { -- 3.0.7 version
        Type = "SCENARIO", 
        Scenario = "SC_WORLD_HUMAN_WILDERNESS_LOOTER", 
        Animation = {dict = "", body = ""}, 
        WaitTime = 5000,

        Display = 'Covering with guts..',
    },

    -- It will be added randomly on zombies based on a chance if they have guts or not.
    GutsContainPercent = 30, -- percentage (%) - 3.0.7 version

    -- This feature is to allow zombies who have specific model and skin preset (like 1 leg - no legs ) to crawl than walking.
    -- (!) TO-DO

        },

    },
```

## How to update?

- You can easily update the modified files by redownloading from the **Cfx.re Portal** and copy-paste on the mentioned directory file paths.
- If new options have been implemented to the configuration file or edited, **DO NOT** copy-paste the new configuration file, otherwise you will get the latest configuration but you will lose all the changes you have made. The proper way updating a configuration file is by finding the new configuration options or the modified ones and do it **manually**.

*Cfx.re Portal **DOES NOT** force-update your configuration file or any files, if it did, you would always lose all the configuration changes you made or would totally break the script, all files are updated or edited manually.*
